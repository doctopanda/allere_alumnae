# ALLERE ALUMNAE | Sonora

Visor geográfico de cobertura del programa de Salud Escolar en Sonora, México. Muestra únicamente metadatos institucionales de CCT y estadísticas generales; **no publica microdatos ni identificadores de menores**.

Fuente: catálogo escolar SEP (coordenadas referenciales), catálogo de filtros de Tableau IMSS con Sonora y ciclo 2025-2026, y corte local de extracción de 2026-10-28.

## Publicación

El repositorio contiene un sitio estático en `index.html`. Para publicarlo, habilitar GitHub Pages en Settings > Pages > Deploy from a branch > main > /(root).

**Importante:** 1,393 CCT completadas en el checkpoint no equivale a 1,393 tablas descargadas o evaluaciones validadas. La base epidemiológica disponible en este entorno sólo corresponde a 194 CCT de un respaldo anterior; no representa la prevalencia estatal.
